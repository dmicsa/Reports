Methodology

Pricing normalization: The system cost ($) column is normalized to complete local-build acquisition cost, not raw add-in card MSRP. Discrete workstation GPUs were converted to system pricing with a fixed $1,600 host allowance, while passive datacenter accelerators use a $3,000 server-platform allowance.

Vendor-sourced fields: VRAM, memory bandwidth, and board power use vendor-published specs where available, including AMD product pages for W7800, W7900, and MI210, NVIDIA Quadro RTX 8000 quick specs, and AMD's Radeon Pro Duo launch material.

Estimated fields: LLM throughput and tokens-per-dollar values are model-side inference estimates based on memory capacity, memory bandwidth, architecture class, and software maturity rather than direct apples-to-apples benchmark runs on identical hosts.
