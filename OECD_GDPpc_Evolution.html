Note: GDP per capita PPP is in current international dollars (not constant). This means values reflect both real growth and price level changes over time. Ireland and Luxembourg figures are inflated by multinational corporate profits booked domestically. All values 2000–2025 are actual observations from a single WDI vintage (2026-07-13) incorporating the ICP 2021 PPP benchmark revision; earlier figures in prior versions of this report (based on the ICP 2017 cycle and IMF projections for 2025) have been replaced throughout.
